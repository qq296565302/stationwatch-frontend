Windows任务计划配置说明
========================

功能：每天8:30自动执行值班记录相关任务

执行内容：
----------
1. 运行 auto_duty.vbs - 生成当日值班工作表
2. 运行 check_lock.vbs - 检查并锁定过期工作表

项目文件结构：
--------------
【bat目录】批处理文件（5个）
  - setup_task_hidden.bat     - 配置任务计划（使用test_run.bat）
  - remove_task.bat           - 删除任务计划
  - run_daily_task.bat        - 每日任务执行脚本
  - run_daily_task_hidden.vbs - VBScript包装器（隐藏窗口）
  - test_run.bat              - 测试运行脚本（手动测试和定时任务都使用）

【vbs目录】VBScript脚本（2个）
  - auto_duty.vbs            - 自动生成工作表
  - check_lock.vbs           - 检查并锁定过期工作表

【scripts目录】Python脚本（4个）
  - fix_encoding.py          - 主配置生成工具
  - check_lock.py            - 生成锁定检查脚本
  - test_path.py             - 路径检测测试工具
  - check_environment.py     - 系统环境检查工具

【docs目录】模板文件（1个）
  - 电子值班表模板.xlsx      - Excel模板文件

总计：12个核心文件 + 1个说明文档

使用步骤：
----------

【部署前检查】
运行 scripts/check_environment.py 检查系统环境：
- ✅ Windows系统（Win7/Win10/Win11）
- ✅ Python 3.x（需要安装并配置环境变量）
- ✅ Microsoft Excel（Office 2007或更高版本）
- ⚠️ 管理员权限（仅配置任务计划时需要）

【首次配置】
1. 复制整个"值班记录表"文件夹到目标机器（例如：D:\值班记录表）
2. 【重要】运行测试脚本验证路径：
   - 双击运行 scripts/test_path.py
   - 检查是否显示"✅ 所有文件检查通过！"
   - 如果显示"❌ 文件结构不完整"，请检查文件夹是否完整
3. 【测试运行】执行测试脚本验证功能：
   - 双击运行 bat/test_run.bat
   - 检查是否成功生成Excel文件
   - 如果有错误，根据提示排查
4. 打开 scripts/fix_encoding.py
5. 修改第67行的供电所名称（如需要）
6. 修改第80行的值班人员名单（如需要）
7. 运行：python scripts/fix_encoding.py
8. 右键点击 bat/setup_task_hidden.bat → 以管理员身份运行
9. 等待配置成功提示
10. 在任务计划程序中手动运行任务测试
11. 完成！

【重要提示】
- 脚本会自动检测路径，无需手动修改硬编码路径
- 请保持文件夹结构完整（bat、vbs、scripts、docs四个子文件夹）
- 不要单独移动或删除任何文件

【查看任务】
方法1：
  - 按 Win+R 打开运行对话框
  - 输入 taskschd.msc 回车
  - 在"任务计划程序库"中找到"值班记录每日任务"

方法2（命令行）：
  - schtasks /query /tn "值班记录每日任务"

【删除任务】
1. 右键点击 bat/remove_task.bat
2. 选择"以管理员身份运行"
3. 等待删除成功提示
4. 完成！

工作原理：
----------
- 每天8:30自动后台运行（不显示窗口）
- 先生成当日工作表（auto_duty.vbs）
- 再检查并锁定过期工作表（check_lock.vbs）
- 完全静默运行，不干扰用户

功能特性：
----------
1. 自动生成每日值班工作表
2. 自动填写值班人员和时间信息
3. 自动添加天气情况下拉列表
4. 次日8:30自动锁定工作表
5. 运行前自动关闭目标Excel文件（不影响其他文件）
6. 自动时间填写功能（需启用迭代计算）

配置修改：
----------
【修改供电所名称】
1. 打开 scripts/fix_encoding.py
2. 找到第67行：Const STATION_NAME = "张店供电中心马尚供电所"
3. 修改引号内的名称
4. 运行：python scripts/fix_encoding.py

【修改值班人员】
1. 打开 scripts/fix_encoding.py
2. 找到第80行：dutyPersons = Array(...)
3. 修改人名（5天一轮换）
4. 运行：python scripts/fix_encoding.py

【修改锁定时间】
1. 打开 scripts/fix_encoding.py
2. 找到第60行：Const DEADLINE_TIME = "08:30:00"
3. 修改时间格式：HH:MM:SS
4. 运行：python scripts/fix_encoding.py

【修改执行时间】
方法1（推荐）：重新运行 setup_task_hidden.bat
方法2：打开任务计划程序，找到任务，右键属性，在"触发器"标签修改时间

注意事项：
----------
1. 需要管理员权限才能配置任务计划
2. 电脑需要在执行时间处于开机状态
3. 任务会在后台静默运行，不显示窗口
4. 如果电脑在执行时间关机，下次开机会自动运行
5. Excel模板文件需要保留在 docs 目录下

常见问题：
----------

Q: 是否可以部署到任何电脑？
A: 可以，但需要满足以下条件：
   1. Windows系统（Win7/Win10/Win11）
   2. 已安装Python 3.x并配置环境变量
   3. 已安装Microsoft Excel（Office 2007或更高版本）
   4. 有管理员权限（仅配置任务计划时需要）

   部署步骤：
   1. 运行 scripts/check_environment.py 检查环境
   2. 复制整个文件夹到目标机器
   3. 运行 scripts/test_path.py 验证路径
   4. 配置任务计划

Q: 定时任务运行时窗口一闪而过，没有执行成功怎么办？
A: 解决步骤：
   1. 运行 bat/test_run.bat 测试基本功能是否正常
   2. 确认能成功生成Excel文件
   3. 运行 scripts/test_path.py 检查文件结构是否完整
   4. 右键 bat/setup_task_hidden.bat → 以管理员身份运行
   5. 在任务计划程序中手动运行任务测试

   关键点：setup_task_hidden.bat 现在使用 test_run.bat 执行任务
   所以手动测试成功的脚本，任务计划执行也会成功

   如果仍然失败，请检查：
   - Python是否正确安装（运行 `python --version` 测试）
   - 文件夹路径是否包含特殊字符
   - 是否有足够的权限
   - 任务计划中的路径配置是否正确

Q: 如何启用自动时间填写功能？
A: 打开Excel → 文件 → 选项 → 公式 → 启用迭代计算

Q: 如何临时禁用任务？
A: 打开任务计划程序，找到任务，右键"禁用"

Q: 如何立即测试任务？
A: 打开任务计划程序，找到任务，右键"运行"

Q: 工作表被锁定了怎么办？
A: 锁定密码：DutyLock2026，可以手动解锁

技术细节：
----------
- 任务名称：值班记录每日任务
- 执行时间：每天 8:30
- 执行程序：cscript.exe run_daily_task_hidden.vbs
- 执行顺序：
  1. auto_duty.vbs（生成当日工作表）
  2. check_lock.vbs（检查锁定过期工作表）
- 锁定密码：DutyLock2026
- 条件：用户已登录时运行
- 设置：后台运行，不显示窗口

文件编码说明：
--------------
- Python脚本：UTF-8编码
- VBScript脚本：GBK编码（中文Windows标准）
- 批处理文件：GBK编码
- Excel模板：xlsx格式（无宏）

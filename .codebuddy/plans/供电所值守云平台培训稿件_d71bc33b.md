## 产品概述
为已基本开发完成的「供电所值守云平台」编写一份 HTML 形式的内部培训稿件，用于向供电所工作人员投屏演示系统功能、使用方法和业务流程。

## 核心功能
- **项目简介**：平台定位、建设目标（让值班更高效）、涵盖范围（供电所值班记录数字化管理）
- **登录指引**：登录入口、用户名密码登录、演示账号说明（值班员/区县管理员/管理员）、忘记密码处理
- **角色权限**：四种角色（值班员、所长、区县管理员、管理员）各自的功能边界与权限差异
- **功能模块**：主控台、值班记录（列表/新建/详情/编辑）、导出管理、系统配置四大模块逐一介绍
- **核心操作流程**：以步骤化的方式演示完整业务流——新建值班记录三步流程、工单处理与标记完成、记录锁定、Excel 导出、系统配置管理
- **常见问题与使用贴士**：超时提醒机制、遗留问题跟进、补录前一天、记住我、工单时限、遗留问题下个班次优先展示等要点

## 视觉要求
- 单文件自包含 HTML（内联 CSS，无外部依赖），可直接在浏览器打开
- 美观、现代、适合投影演示，字号清晰、层次分明
- 信息组织按培训讲述顺序推进，逻辑连贯

## 约束
- 仅生成独立 HTML 培训稿件文件，不修改任何现有源码
- 内容需严格基于已核实的项目实际功能与流程

## 技术方案
### 技术选型
- 交付物为**单个自包含 HTML 文件**，内联 CSS 与少量原生 JavaScript（用于页签切换、流程步骤高亮、平滑滚动等演示交互），无任何外部 CDN 依赖，离线可用、可直接双击在浏览器打开，适配投屏。
- 语言：HTML5 + 语义化结构 + 现代 CSS（flex/grid、渐变、玻璃拟态、动效）。
- 字体：系统字体栈为主（中文环境下回退到 微软雅黑/思源黑体），确保任何机器渲染一致。

### 实施思路
1. 内容来源全部取自已核实的项目代码：路由结构、各视图模板、角色 getter 逻辑、API 文档，保证培训内容与实际产品 100% 一致。
2. 采用"单页滚动 + 章节导航 + 页签切换"结构：顶部固定导航栏含各章节锚点，内容按培训叙述顺序编排，关键功能用视觉化卡片/步骤条呈现，提升投屏演示的引导性。
3. 页面章节划分：
   - 封面（平台名、口号、培训说明）
   - 项目简介与目标
   - 技术架构与角色权限
   - 功能模块总览（主控台/值班记录/导出/系统配置）
   - 核心操作流程（新建记录三步、工单标记完成、锁定、导出、系统配置）
   - 常见问题与使用贴士
   - 结语
4. 每个核心流程用"分步步骤条 + 说明卡"形式呈现，模拟实际页面操作路径，帮助培训者演示时对照真实界面讲解。

### 性能与可靠性
- 无网络请求、无外部资源，加载即用。
- 交互（导航高亮、页签切换、步骤展开）使用纯 CSS/CSS 变量与少量 JS，轻量无依赖。

### 设计说明
- 主题延续项目自身深色科技感配色（主色 #00D4FF 青色系、深色背景、玻璃拟态卡片、渐变光晕），与产品视觉一致，增强培训代入感。
- 标题层级清晰、正文字号偏大（适应投屏远距离观看），代码/口令类内容使用等宽字体。
- 采用柔和入场动画与卡片悬浮效果，提升演示质感。

## 设计风格
采用与产品一致的深色科技风格（Fluent 玻璃拟态 + 渐变光晕），适合投屏演示。整体为单页纵向滚动结构，顶部固定章节导航，各章节以玻璃拟态卡片、步骤条、数据指标卡呈现。强调信息层级：封面大字标题、章节标题醒目、正文与提示偏大字号保证远距离可读。使用青色(#00D4FF)主色搭配深蓝黑背景，点缀绿(完成/成功)、琥珀(超时/遗留)、红(锁定/警告)等语义色，与系统内 StatusBadge 语义一致。关键业务流用横向/纵向步骤条展示操作路径，穿插「演示账号」「权限对照」「常见问题」等便于演示者讲解的信息卡。
## 布局与交互
- 顶部 sticky 导航：平台名 + 各章节锚点链接，滚动时高亮当前章节
- 封面：全屏渐变背景 + 平台口号 + 培训副标题 + 向下滚动提示
- 章节：标题带编号（01/02/03…）+ 描述 + 内容卡片网格
- 核心流程章节：步骤条（StepIndicator 风格）编号节点，可点击展开各步骤详细操作说明
- 页脚：版本信息、版权
- 微交互：卡片 hover 上浮、章节渐入动画、步骤高亮切换

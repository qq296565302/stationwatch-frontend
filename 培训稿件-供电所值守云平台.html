01 · 项目简介

为什么建设这个平台？

供电所值守云平台将传统的纸质值班记录、手工台账，升级为「在线记录 + 工单化管理 + 自动统计 + 一键导出」的数字化平台， 让每一次值班、每一张工单、每一条遗留问题都清晰留痕、可追溯、可分析。

📝

值班记录数字化

值班日期、天气、值班班组、值班事项在线填报，替代纸质值班表，数据实时入库，随查随用。

⚙️

工单流程化管理

每条报修/业务事项作为独立工单，记录受理内容、客户、联系方式、办理人员与处理结果，支持标记完成、超时提醒。

📊

数据统计分析

主控台自动汇总接单量、完成率、响应时长、业务分布、接单时段热力图、重复工单等，为管理决策提供依据。

🗂️

遗留问题闭环

遗留问题逐条登记、确认解决、下个班次优先展示，确保「问题不过夜、班班有交接」。

📤

Excel 一键导出

按月 / 按区间批量导出值班记录为 Excel，保持原始电子值班表模板格式，报表制作不再手工誊抄。

🔐

分级权限管控

值班员、所长、区县管理员、管理员四类角色，职责清晰，操作留痕，数据安全可控。

02 · 技术架构

平台由什么构成？

平台采用「前后端分离」架构，前端负责界面交互，后端提供业务接口与数据服务，登录鉴权全程加密。

🖥️

前端 · 供电所值守云平台前端

  • Vue 3 + Pinia 状态管理 + Vue Router 路由
  • 深色科技风界面，适配各类屏幕与投屏演示
  • 页面模块：主控台 / 值班记录 / 导出管理 / 系统配置
  • 浏览器直接访问，无需安装客户端
⚙️

后端 · 供电所值守云平台后端

  • Nest.js 10 + TypeScript 5 构建
  • JWT 双令牌鉴权（AccessToken 2 小时 / RefreshToken 7 天）
  • 提供值班记录、工单、字典、仪表板、导出、排班等 REST 接口
  • Swagger 在线接口文档，便于联调与调试
03 · 登录指引

如何进入系统？

在浏览器中打开平台地址，使用分配的用户名和密码登录。登录页支持「记住我」，保持登录状态更便捷。

🔑 登录步骤

① 打开系统地址浏览器访问
② 输入分配的用户名由管理员分配
③ 输入密码首次登录后建议修改
④ 点击登录进入主控台
💡
忘记密码时请勿在页面操作，直接联系系统管理员重置密码即可；勾选「记住我」可保持登录状态。
04 · 角色权限

四种角色，各司其职

系统按岗位职责划分四种角色，权限边界清晰：值班员聚焦日常记录，所长负责审核锁定与导出，区县管理员管理本区县站点账号，管理员拥有全部管理权限。

值班员

日常记录主力

  • 查看本所值班记录
  • 创建 / 编辑自己的记录
  • 填写工单、标记完成
  • 跟进遗留问题
所长

记录审核把关

  • 查看 / 编辑全所记录
  • 锁定已完成的记录
  • Excel 导出
  • 配置本所值班规则
区县管理员

区县组织管理

  • 管理本区县供电所站点
  • 管理值班员账号
  • Excel 导出
  • 不参与值班记录编辑
管理员

全局系统管理

  • 用户 / 站点 / 系统配置
  • 删除、解锁记录
  • 操作日志审计
  • 全部模块权限

06 · 核心操作流程

一步一步，照做就会

以下按真实操作路径拆解五大核心流程。点击每个流程节点可展开详细操作说明，便于现场对照演示。

流程一 · 新建值班记录（三步）

值班员登录后，点击「新建值班记录」，依次完成基本信息 → 值班事项 → 其他事项三个步骤，最后提交。

1
填写基本信息 值班日期 · 天气 · 值班班组 · 所属站点
值班日期可选「今天」或「昨天」，支持补录前一天记录。
天气情况通过图标点选（晴天 / 多云 / 雨天 / 雷雨 / 雪天 / 雾天）。
值班人员按当天排班自动带出班组，无需手工填写。
所属站点系统自动填充，只读。
▼
2
录入值班事项 逐条添加工单，最多 11 条
受理时间默认当前时刻，可调整。
业务类型 / 受理内容下拉可选项，也可直接输入新内容。
客户名称 / 联系电话 / 联系地址必填项，手机号需 11 位。
办理人员 / 处理结果记录处理责任人；填写处理结果后可标记完成。
▼
3
填写其他事项与遗留问题 提交记录
其他事项记录非例行事项，如会议、培训、设备异动等。
遗留问题登记待跟进事项，将在下个班次优先展示。
提交系统按「同站点同一天」智能合并，同一天重复提交会合并工单而非重复创建。
注意事项受理时间不得晚于当前时刻；未填必填项的工单会给出确认提示。
▼

流程二 · 工单处理与标记完成

进入记录详情，时间线展示每条工单的受理 → 完成过程；填写处理结果后即可标记完成，系统自动记录完成时间。

1
进入记录详情
入口在值班记录列表点击某条记录。
查看顶部展示日期、天气、值班员、状态与完成度环形进度。
▼
2
点击工单查看 / 填写处理结果
抽屉弹窗点击任意工单弹出完整信息（业务类型、客户、联系方式、地址、办理人员）。
处理结果从下拉选择或直接输入。
▼
3
标记完成
操作点击「标记完成」，系统强制记录当前时间为完成时间。
超时提醒未完成工单临近时限变黄、超时变红，自动提示。
▼

流程三 · 锁定值班记录

当某天记录全部工单已完成，由所长（或管理员）执行锁定，锁定后记录不可再修改，确保数据正式归档。

1
确认记录已全部完成
前置条件该记录完成数 = 事项总数（进度 100%）。
▼
2
点击「锁定记录」
权限仅所长与管理员可见锁定按钮。
确认弹出确认框，确认后即锁定。
▼
3
锁定生效
状态记录变为「已锁定」，编辑按钮对值班员隐藏。
解锁仅管理员可解锁已锁定记录。
▼

流程四 · 导出值班记录 Excel

所长 / 区县管理员 / 管理员可在「导出管理」按需生成 Excel 报表。

1
选择导出类型
月度导出选择具体月份，一次导出整月记录。
区间导出自定义起止日期范围。
▼
2
配置导出选项
内容勾选是否包含「其他事项」「遗留问题」。
格式是否使用原始 Excel 模板、是否合并到单个工作表。
▼
3
开始导出并下载
预览右侧展示预计导出条数、文件名与大小。
下载点击「开始导出」，浏览器自动下载 xlsx 文件。
历史导出记录保存在「导出历史」，可随时重新下载。
▼

流程五 · 系统配置管理（所长 / 管理员）

在「系统配置」中管理站点、账号、排班与业务规则，让平台贴合本所实际。

1
站点信息与值班员管理
站点信息维护供电所名称、所属区县。
值班员管理添加值班员、编辑资料、分配角色、重置密码。
▼
2
配置值班排班
规则固定轮值、每组一天、周期循环。
设置起始日期、轮换周期、班组数量与成员。
联动排班配置后，新建记录会自动带出当天值班班组，主控台展示排班表。
▼
3
设置值班规则并保存
每班最大事项数默认 11 条。
工单时限默认 45 分钟，未完成超时自动提醒。
历史修改 / 自动开始时间 / 遗留提醒等开关由管理员控制。
保存点击「保存值班规则」即时生效。
▼
07 · 常见问题与使用贴士

使用中常见问题

这些高频问题在培训演示时务必讲透，帮助值班员快速上手。

⏱️

工单为什么会「超时」？

系统按「工单时限」（默认 45 分钟）判定：未完成工单超过时限标红「已超时」，临近时限变黄提醒。可通过系统配置调整时限。

🔁

怎么补录昨天的记录？

新建记录时，值班日期可选择「昨天」进行补录。历史记录是否可改，由管理员在「历史记录修改限制」中控制。

📌

遗留问题如何跟进？

遗留问题逐条登记，下个班次优先展示；处理完成后由有权限的值班员/所长「确认解决」，系统记录解决人与时间。

🔐

为什么不能编辑别人的记录？

值班员仅可编辑自己创建的值班记录；编辑他人记录需要所长或管理员权限，锁定记录仅管理员可编辑。

📤

导出后文件在哪？

导出完成后浏览器自动下载 xlsx 文件；同时可在「导出历史」中重新下载任意历史导出文件。

🔄

同一天重复建记录会怎样？

不会重复创建。系统按「同站点同一天」智能合并：已有工单带 id 则更新、无 id 则追加，其他事项与遗留问题按行追加合并。

🗝️

忘记密码怎么办？

页面不支持自助找回，请联系系统管理员重置密码。登录页的「忘记密码？」即提示此操作路径。

📊

如何快速定位某天记录？

在值班记录列表使用搜索框（值班员 / 事项内容）、状态筛选、日期区间筛选，即可快速定位；支持表格 / 卡片两种视图切换。
